A program that draws one newspaper poster summing up Wednesday 18 November 2026's world news — the Gulf drone attacks, APEC opening in Shenzhen, the Kerch Bridge, Alaska's Senate race, and more — and writes it to `/output/entry.png`.

Run it with Node 22, standard library only, no network:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
